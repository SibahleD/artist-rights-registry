# Streaming service logos

One SVG per service, named after the service id in `src/data/services.ts`. If a file is missing, the release page shows the service's name as text instead.
`other.svg` is the generic icon for any store not in the list.

The buttons have a light background (#f3f4f7), so logos must be dark enough to read on it (aim for a 3:1 contrast or better).

Files:
amazon_music.svg, apple_music.svg, audiomack.svg, bandcamp.svg, beatport.svg, boomplay.svg, deezer.svg, itunes.svg,
other.svg, soundcloud.svg, spotify.svg, tidal.svg, youtube.svg, youtube_music.svg
